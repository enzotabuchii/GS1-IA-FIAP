# Mission Control AI - Global Solution 2026.1

## O Que o Projeto Faz
Este é um sistema de monitoramento inteligente para controle operacional de uma missão espacial experimental desenvolvido em Python. O sistema simula dados de telemetria essenciais (temperatura, energia e comunicação), aplica lógica interna automatizada de tomada de decisão para contenção de danos e utiliza o modelo de linguagem Llama 3.2 (via Ollama no Google Colab) para gerar análises preditivas e relatórios críticos em tempo real.
